# 还债总账

> **状态**：现行（2026-10-04 立）。全项目技术债的**唯一台账**：一条债一行，带出处、严重度、
> **测量状态**、归属批次。
>
> **它不是什么**：不是计划（批次排期在各 `*_plan.md`）、不是教训叙事（教训就近写**当前任务文档**）、
> 不是机制说明（`技术概念.md`）、**不是数据仓库**——结案账目量出来的数字与主 agent 亲验记录一律搬进
> **`docs/还债实测数据.md`**。**它只回答"还欠哪些、每条走到哪一步"**。
>
> **主轴（2026-10-04 用户拍板）**：**先观测，不动渲染**——本账的默认动作是**补量具 + 出数**，不是改渲染。
> 理由 = 当时最大的发现不是"某处慢 / 某处噪"，而是**这个项目对自己现在的样子没有数**。观测面四条
> （债-01…04）已清偿，量具 = `just cpu` / `just regress` / `just imgqa selftest`。
>
> **勾账纪律**：一条债只有三种终态——① **结案**（有数字 + 有裁决，教训写进**当前任务文档**（就近、
> 推翻即删）并在此标"已结案 + 指针"）；② **否决**（写进 §3 附理由与出处）；③ **降级**（写明触发条件）。
> 不允许"看过一眼就算完"。
>
> **出处指针纪律**：本账引用代码**优先写符号名/函数名**（如 `Renderer::attachmentLayouts`、
> `IzbShadow::recordFrame`），无符号可锚才用行号——纯 `文件:行号` 指针改一次文件就漂一次。同理**不在
> 本账抄哈希 / 字节数 / 条目数**（抄一次漂一次），写"以某符号 / 某红线声明块为准"。
>
> **定期删（口径，不做逐条勾账）**：结案账目攒到读数开始被反复引用，就清一次正文——**数据搬进
> `docs/还债实测数据.md`、叙事去 `git log -p docs/还债总账.md`、§1 只留一行终态 + 指针**。已执行两次：
