# 脚本长期规划

> **状态**：规划（2026-09-14 立）。**长期线，独立于 next_roadmap 阶段序列**（不进 Phase 编号）；
> P0 spike 已通（`script_spike/`，Linux + clang 22.1.8 PASS）。

## 0. 目标与三层分工

引擎脚本化 = 让"引擎之上的逻辑"可插、可换、可热重载，而不改引擎本体。三层，各司其职：

| 层 | 载体 | 消费者 | 热路径? |
|---|---|---|---|
| 扩展层 | C++ 脚本 so（import 引擎 API 模块） | 引擎团队 | ✅ per-entity 级 |
| 用户层 | JS（QuickJS 嵌入，远期） | 外部用户 | ❌ 逻辑级（per-entity 热循环不进 JS） |
| 配置层 | Lua（现状维持） | 所有人 | 只读数据，不做脚本 |

**明确不做**：wasm（热路径 per-entity 边界拷贝/线性内存共享契约，今天的工具链撑不住
"零拷贝共享"；沙箱/语言无关的好处在独狼项目无对应需求）。Lua 脚本化也不做——sol2 配置
沙箱现状挺好，"配置即 Lua"的边界保持。

## 1. 关键决策（含被否决项）

1. **模块 ABI 路线 > C ABI 路线**（2026-09-14 讨论定案）：脚本 `import` 引擎的**窄 API 模块**
   （interface unit = POD 组件 + system 签名 + 回调原语；impl = 引擎），编译期拿 BMI，
   运行时符号解析到宿主。**优势 = 失败时点前移**：契约破了脚本编不过（build 时死），
   而非 C ABI 的 load 期 hash 握手（runtime 死）——配本项目"契约先行"脾气。
   C API 降级为**将来给 JS 的生成物**（从 API 模块生成，单一真相源不变），不是手撸第二契约。
2. **依赖方向 = 脚本认识引擎（经 BMI），引擎只认脚本的入口符号名**（`extern "C"` 约定，
   如 `rgl_script_create`）——引擎编译期对脚本零耦合。
3. **不做 C++ 沙箱**：C++ so 无法真禁 IO（fd/mmap/线程/OOM 全在），style_check 白名单是
   honor system。威胁模型 = "自己写错"而非"恶意脚本"，独狼规模可接受；**文档不得称沙箱**。
4. 异常不过界（跨 dlopen 无 unwinder = terminate 风险）、std 容器不过界（POD only）——
   与走哪条 ABI 路无关的硬约定。

## 2. 架构（定型前不动实现）

```
[引擎宿主 exe]
  rgl.script_api 模块（窄接口：POD 组件 / System 签名 / for_each 回调原语 / 版本）
  ScriptHost（dlopen/dlsym/加载期版本握手/帧边界 unload-reload/白名单 lint 钩子）
  ECS system 列表：内建 system + 脚本 system（生成 wrapper 调脚本入口）
        ▲ dlopen(脚本.so) + dlsym("rgl_script_create")
[脚本 so]
  import rgl.script_api;   ← 编译期 BMI（-fmodule-file，同编译器同 flags）
  extern "C" rgl_script_create(api) → 注册 system 回调
  system 回调体内调 API（引擎驱动 for_each，回调代码在 so 内）
```

- **迭代原语** = `api->for_each_entity(mask, script_cb)`：entt 不过界，引擎驱动回调，
  per-entity 边界调用（ns 级）热路径可接受；脚本无法自持 registry。
- **system 定义**（远期 P2）：Lua 描述 system（组件 mask / 执行序 / 参数）→ codegen
  生成 wrapper（复用 reflection_tool/generator 既有管线 DNA）→ wrapper 调脚本入口。
  当前阶段手写 system 注册即可，codegen 等 ECS 面静止。
- **热重载**：脚本 so 的 unload/reload 与 SPV/config 热重载共用帧边界换入路径
  （submit 后、录制前）——一次基建三处收益（shader/config/脚本）。

## 3. 红线约定（进 style_check 白名单 lint）

1. 脚本边界函数 noexcept（入口 + 所有过界回调）；错误经返回码/expected 语义，不抛。
2. 过界类型 = POD（API 模块 interface 里能出现的类型即白名单；std 容器/字符串不过界）。
3. 脚本构建 pin 引擎同款编译器 + 关键 flags（justfile `script-build` recipe 强制同源，
   同 SLANG_FLAGS"唯一声明点"纪律）。
4. 脚本入口幂等可重入（热重载二次 load 不残留全局状态）。
5. 脚本禁用 IO/线程/第三方（白名单 lint；honor system，文档不称沙箱——见 §1.3）。

## 4. 分阶段

| 阶段 | 内容 | 时机 | 验收 |
|---|---|---|---|
| **P0** | so×module 兼容性 spike（`script_spike/`） | ✅ 完成 2026-09-14 | BMI 跨单元 import + exe 符号导出（--export-dynamic）+ dlopen 解析 + 回调/POD 过界，全 PASS |
| **P1** | 单脚本 so 实现一个真 system（per-frame 力/自转级）+ 加载期版本握手 + 红线 lint 进 style_check + 帧边界 unload/reload（与 SPV/config 热重载合并施工） | Phase 8.5 热重载批（顺带）或紧随其后 | 脚本 system 进 ECS 执行列表且热换生效；ABI 破坏 = 脚本编译期报错（留证）；异常跨边界行为实测留证 |
| **P2** | Lua→codegen system 生成 + 更多 system 类型 + API 模块扩面 | **Phase 10 后**（ECS 面静止是硬前提——阴影会动 system 结构，移动靶上刻合同 = 返工） | 一个 Lua 描述生成可运行 system；API 模块 interface 冻结 v1 |
| **P3** | QuickJS 用户层 + 从 API 模块生成 C ABI | 有余力再说（当前最关心的是 P1） | 用户 JS 调逻辑级 API 跑通 |

## 5. P0 spike 结论（`script_spike/`，clang 22.1.8 / Linux）

三点全 PASS（细节见其 README）。三个落地注意：
1. 宿主 **exe** 默认不导出符号 → 必须 `-Wl,--export-dynamic`（或显式导出清单）——
   引擎主构建要加这个链接 flag（或 P1 时用 version script 精确导出 API 符号）。
2. 模块符号 mangle 含模块名（`_ZW9spike_api...`）——脚本经 BMI 编译自动一致，无手工风险；
   脚本入口仍用 `extern "C"` 免 dlsym 猜 mangle。
3. BMI 与消费方同 `-std`（本 spike 全 C++23）。
未验（P1 清单）：异常跨边界、脚本自身为模块（.cppm→so）、reload 语义、Windows（第二梯队不验）。
