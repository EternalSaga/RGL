# Zed 快捷键配置

> **状态**：现行（Zed 编辑器快捷键/任务/调试配置说明，与代码无关，稳定文档）

## 快捷键映射

| 快捷键 | 操作 | 说明 |
|---|---|---|
| `Ctrl+Shift+B` | `task::Rerun` | 重新运行最近的任务（通常用于重新构建） |
| `F5` | `debugger::Start` | 启动调试面板/选择调试配置 |
| `Shift+F5` | `debugger::Stop` | 停止当前调试会话 |

## 其他常用快捷键

| 快捷键 | 操作 | 说明 |
|---|---|---|
| `Ctrl+Shift+R` | `task::Spawn` | 打开任务选择器，选择要运行的任务 |
| `` Ctrl+` `` | 终端面板 | 切换内置终端面板显示 |
| `Ctrl+Shift+P` | 命令面板 | 打开命令面板，可搜索所有可用命令 |

## 调试配置

调试配置位于 `.zed/debug.json`：
- 使用 CodeLLDB（LLDB）调试器
- 自动运行 `just build-debug` 构建 Debug 版本
- 工作目录自动指向 `build/rgl/`（确保能找到 SPV 着色器文件）

## 任务配置

可用任务位于 `.zed/tasks.json`：
- `Configure (CMake)` - 单独运行 CMake 配置
- `Build (Release)` - 一键配置并编译 Release 版本
- `Build (Debug)` - 一键配置并编译 Debug 版本
- `Build (Default)` - 自动先 config 再 build（适合增量编译）
- `Run` - 运行程序（`just run`）
- `Clean (CMake)` - 增量清理
- `Clean All (Remove Build Dir)` - 删除整个 build 目录（`just clean-all`）
- `Clean All + Rebuild` - 彻底清理后重新构建

## 配置文件位置

- 快捷键配置：`.zed/keymap.json`
- 任务配置：`.zed/tasks.json`
- 调试配置：`.zed/debug.json`
- 项目设置：`.zed/settings.json`
